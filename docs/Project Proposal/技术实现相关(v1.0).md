# 一，结构体

- `User`：负责多用户管理，满足登录、注册、改密和数据隔离需求。
- `Card`：对应知识卡片实体，支持录入、修改、删除、查询、分类、统计与复习。
- `WrongQuestion`：对应错题实体，既能独立管理，也能转化为知识卡片。
- `ReviewLog`：保存用户每次复习行为，支撑统计分析与答辩展示。
- `ReviewTask`：程序运行时临时生成的今日复习队列，不一定落盘。

# 四，文件设计方案

## 1. 文件清单

### `users.txt`

保存全部用户信息。

### `cards.txt`

保存全部知识卡片。

### `wrongs.txt`

保存全部错题。

### `review_logs.txt`

保存全部复习日志。

### `system_config.txt`

保存全局编号、自定义设置等。

## 2.存储格式:文本行 + 分隔符

每一行表示一条记录，字段之间用 `|` 分隔。

```
1|alice|123456|student|2026-04-23|1
```

## 3.各文字段设计

### `users.txt`

```
userId|username|password|role|createDate|active
```


示例：
```
1|alice|123456|student|2026-04-23|1  
2|bob|888888|student|2026-04-23|1
```


---

### `cards.txt`

```
cardId|userId|subject|chapter|title|front|back|tags|difficulty|mastery|reviewCount|correctStreak|intervalDays|easeFactor|createDate|lastReviewDate|nextReviewDate|archived|active
```

示例：
```
1001|1|数据结构|线性表|顺序表定义|什么是顺序表？|用连续存储空间存放线性表元素|线性表,定义|3|50|0|0|1|2.5|2026-04-23||2026-04-24|0|1
```

---

### `wrongs.txt`

```
wrongId|userId|subject|chapter|question|correctAnswer|wrongAnswer|reason|errorType|linkedCardId|mastery|reviewCount|correctStreak|intervalDays|createDate|lastReviewDate|nextReviewDate|mastered|active
```


示例：

```
2001|1|高数|极限|求 lim sinx/x|1|0|忘记基本极限公式|概念不清|-1|30|0|0|1|2026-04-23||2026-04-24|0|1
```


---

### `review_logs.txt`

```
logId|userId|itemId|itemType|reviewDate|result|oldInterval|newInterval|oldMastery|newMastery
```


示例：

```
3001|1|1001|card|2026-04-23|2|1|3|50|60  
3002|1|2001|wrong|2026-04-23|0|1|1|30|15
```

## 4. 文件读写策略

### 程序启动时

- 读取 `users.txt`
- 读取 `cards.txt`
- 读取 `wrongs.txt`
- 读取 `review_logs.txt`

### 用户执行增删改操作后

- **立即保存对应文件**
- 这样即使程序意外退出，数据损失也最小

### 用户退出登录或退出系统时

- 再统一保存一次所有数据
