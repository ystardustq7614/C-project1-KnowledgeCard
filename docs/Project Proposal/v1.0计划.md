## 3. 本次实现策略

### 原则 1：先做“能跑”的主流程

优先打通以下最小闭环：

> 启动程序 → 注册/登录 → 新增卡片/错题 → 今日复习 → 写入日志 → 查看统计 → 退出重进数据仍在

### 原则 2：先写稳定规则，再写交互细节

- 先把结构体、存储、工具函数、编号生成写稳定
    
- 再写菜单与模块功能
    
- 最后补优化和提示语
    

### 原则 3：每一批改动都可以单独验证

不要一开始就把所有菜单和功能全部堆到一起。

#include "storage.h"

#include "utils.h"

vector<Card> cards;

void showMainMenu();

    initFilesIfNeeded();

    while (true) {
        showWelcomeMenu();
    }

    saveAllData();
    return 0;
}

    cout << "==============================\n";
    cout << "知识卡片与错题复习管理系统\n";
    cout << "==============================\n";
    cout << "1. 用户登录\n";
    cout << "2. 用户注册\n";
    cout << "0. 退出系统\n";
    cout << "请选择：";

    string line;
    getline(cin, line);

    int choice;
    if (!parseInt(line, choice)) {
        cout << "输入无效，请重新输入。\n";
        pauseScreen();
        return;
    }

    switch (choice) {
        case 1:
            if (loginUser()) {
                showMainMenu();
            }
            break;
        case 2:
            registerUser();
            break;
        case 0:
            saveAllData();
            exit(0);
        default:
            cout << "菜单选项不存在。\n";
            pauseScreen();
    }
}

void showMainMenu() {
    while (currentUserId != -1) {
        cout << "==============================\n";
        cout << "主菜单（当前用户：" << currentUsername << "）\n";
        cout << "==============================\n";

        cout << "2. 错题管理\n";
        cout << "3. 今日复习\n";

        string line;
        getline(cin, line);
        int choice;
        if (!parseInt(line, choice)) {
            cout << "输入无效，请重新输入。\n";
            pauseScreen();
            continue;
        }

        switch (choice) {
            case 1:
                cout << "[待实现] 知识卡片管理\n";
                pauseScreen();
                break;
            case 2:
                cout << "[待实现] 错题管理\n";
                pauseScreen();
                break;
            case 3:
                cout << "[待实现] 今日复习\n";

                break;

                changePassword();
                break;
            case 0:
                logoutUser();
                break;
            default:
                cout << "菜单选项不存在。\n";
                pauseScreen();
        }

}

## 15. 已知限制（实现阶段继续保持）

- 所有文本字段仅支持单行输入
    
- 文本中不允许包含 `|`
    
- 所有文本输入统一使用 `getline`
    
- 数字输入先读取整行再解析
    
- `linkedCardId` 暂不参与核心业务
    
- V1 不实现数据维护、错题转卡片、SM-2、热度衰减等增强项
    

---


## 17. 结论

现在 V1 已经具备进入编码的条件。最稳的推进方式是：

> 先交付一个“能启动、能登录、能落盘”的工程骨架，再逐步把卡片、错题、复习、统计模块填进去。
