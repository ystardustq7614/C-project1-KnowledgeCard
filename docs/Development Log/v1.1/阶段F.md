### 【项目闭环报告：知识卡片与错题复习管理系统 V1.1】

**1. 项目最终目标回顾**
在 V1 版本跑通 SM-2 记忆算法和控制台基础骨架的基础上，V1.1 致力于打通系统内部的“任督二脉”：让错题能够沉淀为卡片，让数据具备维护的后悔药，并让用户的交互体验趋近于现代化 CLI 工具。目前，所有目标均已实现。

**2. 已实现功能清单**
- [x] **数据基建升级**：错题引入 `errorType`，全面兼容持久化存储。
- [x] **错因统计分析**：独立统计并展示“粗心、概念不清”等不同错因的分布。
- [x] **错题流转知识**：实现了从“记录错题”到“一键转化新卡片”的业务闭环（联动 `linkedCardId` 拦截重复转换）。
- [x] **多维数据检索**：支持按学科、章节、标签对卡片与错题进行过滤筛选。
- [x] **智能排序策略**：支持卡片按“创建时间”、“下次复习时间”、“掌握度”进行顺序重排。
- [x] **安全数据维护**：内置“数据维护”入口，支持对已逻辑删除的卡片和错题进行查询与复活。
- [x] **体验防呆重构**：引入动态表现层映射（Display Map），完全隐藏丑陋的主键 ID，全流程“序号化”点按操作。

**3. 未实现 / 主动放弃的功能清单**
- **测试练习模式**：目前仍以复习为主，未引入随机组卷测试。
- **彻底物理删除**：出于安全考虑，目前仍保留纯“逻辑删除”。
- **数据库替代**：维持现有基于纯文本的极简 I/O 方案。

**4. 最终技术栈与目录结构**
- **技术栈**：C++17 (纯 STL 无第三方依赖), 控制台 UI, 纯文本序列化 I/O。
- **核心文件**：
  - `src/globals.h`, `models.h` (全局状态与数据契约)
  - `src/main.cpp`, `utils.cpp` (路由分发与工具箱)
  - `src/storage.cpp` (持久化中心)
  - `src/user.cpp` (鉴权)
  - `src/card.cpp`, `wrong.cpp`, `review.cpp`, `stats.cpp`, `maintenance.cpp` (解耦的五大核心业务模块)
  - `data/*.txt` (数据文件存放区)

**5. 关键设计决策回顾**
- **联动操作必持久化**：在“错题转卡片”中，强制执行跨模块 `save`，保证两张表的一致性。
- **分离索引与主键**：放弃大改持久化或引入 UUID，而是利用静态 `vector<int>` 在展示时动态生成映射。这不仅挽救了用户体验，也保住了系统极致简洁的架构。
- **逻辑删除**：让 `active` 标志位贯穿所有模块的业务逻辑，配合专门剥离出的 `maintenance.cpp`，实现了极低成本的数据安全网。

**6. 完整版本演进摘要**
- `v1.0`：完成基础骨架建设，SM-2 算法引入，鉴权与 CRUD 闭环。
- `v1.1-PhaseA`：完成错题数据模型扩充（支持 `errorType`）。
- `v1.1-PhaseB`：接入错因录入逻辑与数据统计面板。
- `v1.1-PhaseC`：打通“错题转卡片”的转化流。
- `v1.1-PhaseD`：构建筛选与排序接口。
- `v1.1-PhaseE`：落地“查看/恢复”逻辑删除记录模块。
- `v1.1-Final`：部署统一的动态表现层映射，彻底解决交互 ID 暴露问题。
