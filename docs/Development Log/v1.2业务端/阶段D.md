【当前目标】
完成 V1.2 迭代的【阶段 D：随机自测练习模块】。在死板的 SM-2 日常到期复习之外，我们终于提供了一个可以主动刷题、脱敏无压的练习入口，并与刚刚完成的智能推荐算法形成了业务闭环。

【本轮计划】
1. 新建 `practice` 模块，承载独立的练习业务逻辑。
2. 实现“随机抽查测试”：支持设定抽查数量，无差别混刷。
3. 实现“薄弱点专项突破”：联动 Phase C 的算法，直接向用户最薄弱的章节发起“专项歼灭战”。
4. 将练习中心插入到系统主菜单中。

【实现 / 修改】
我完成了以下核心开发：

**1. 新增独立模块 `src/practice.h` & `src/practice.cpp`**
- 引入了 `<random>` 与 `<chrono>` 库，利用系统时钟作为种子，通过 `std::shuffle` 实现了绝对的随机洗牌（避免了以往按顺序背题导致的惯性记忆）。
- 实现了 `startRandomPractice()`：
  - 用户可以自定义抽取题目数量（默认 10 题），系统会从全局活卡片中抽取。
  - 采用经典 Flashcard 体验：显示题目 -> 阻塞等待回车 -> 显示答案 -> 询问是否答对。
  - **无压设计**：练习过程绝不会修改卡片的 `mastery` 掌握度，也不会触发修改 `cards.txt`，答错不会受到算法惩罚，纯粹用于考前突击或日常摸底。
- 实现了 `startWeaknessPractice()`：
  - 直接调用上个阶段刚写好的 `calculateWeakestChapters` 纯函数，找出 Top 1 薄弱点。
  - 圈定该学科和该章节下所有的知识卡片组成局部题库。
  - 对题库进行限制（最多单次 15 题防疲劳），进行一轮专项集中轰炸。

**2. 路由组装 `src/main.cpp`**
- 主菜单界面在“3. 今日复习”和“5. 统计分析”之间，平滑插入了“4. 自测练习中心”。
- 把原先 4、5、6 选项顺延到了 5、6、7。

【验证方式】
后台执行命令：`g++ src/*.cpp -o project1.exe -std=c++17 -Wall`。
**结果：Exit code 0。模块组装与编译完美通过。**
