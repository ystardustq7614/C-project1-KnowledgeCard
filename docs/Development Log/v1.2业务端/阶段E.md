### 【项目闭环报告】

**1. 项目最终目标回顾**
我们要将一个机械、刻板的“增删改查”程序，升级为一个具备智能调度能力、脱敏无压练习能力，且能够根据艾宾浩斯规律自动惩罚偷懒行为的【智慧型卡片系统】。并且，它必须好用、好看，还要保持纯单体编译的轻量。

**2. 已实现功能清单**
✅ **纯粹的算法底座**：成功将业务与算力彻底切分（`algo_sm2`, `algo_decay`, `algo_recommend`），算法函数内不存在任何全局变量的羁绊。
✅ **直觉化极简评分**：抛弃了 0-5 档这种让大脑宕机的评分，变为极简的【1=忘记、2=模糊、3=记牢】。
✅ **真正的物理删除**：通过 `erase-remove_if` 实现了 O(N) 级别的一次性清盘回收操作。
✅ **多维度组合追踪**：支持跨维度查询（学科+章节+关键词），不再大海捞针。
✅ **记忆降级惩罚**：全局扫描检测，一旦逾期未复习，毫不留情地扣掉热度并腰斩记忆间隔。
✅ **精准薄弱点拦截**：聚合卡片与错题池，算法自动置顶最薄弱章节。
✅ **脱敏自测引擎**：提供了完全乱序抽查与“定向歼灭”最弱章节的突击模式，且答错不扣日常信用分。
✅ **极客 TUI 视觉**：引入 ANSI 全彩渲染。

**3. 未实现 / 主动放弃的功能清单**
- 全量 UI 着色：主动放弃。我们只在关键路径上色，避免代码库成为被转义符吞噬的意大利面条。
- 本地数据库接入：主动放弃。为了坚持能随时随地一个 `g++` 就把项目跑起来，我们仍然选用了灵活的内存容器 + Txt 文本序列化。

**4. 最终技术栈与目录结构**
- 语言：纯正的 **C++17**（无任何第三方繁重类库）
- 架构：`main.cpp` (控制枢纽) -> `业务逻辑模块` -> `algo_核心算法` -> `storage文本持久化`
- UI 方案：原生 Windows API VT100 透传机制 + ANSI 转义流。

**5. 关键设计决策回顾**
- **智能推荐的统一数据契约**：在做薄弱点分析时，我没有分别写两个函数查错题和卡片，而是设计了统一的 `RecommendInputItem`。卡片和错题在灌入算法前先被“降维”统一格式，这种高内聚的抽象极其优美，未来就算接入第三种数据源也能完美适配！
- **练习隔离策略**：所有的练习测试中，用户依然能够获得答案与快感，但 `saveCards` 的接口被死死锁住。让复习归复习（记录真实记忆），练习归练习（纯粹刷题发泄）。

**6. 完整版本演进摘要（从首版到当前版）**
- **V1.0 **：从零拔起，实现数据流的创建、持久化与账号登录闭环。
- **V1.1 **：解决了大量的易用性技术债，特别是消除了“内部自增 ID 外泄”的严重反人类设计。
- **V1.2 **：剥离核心算法，系统开始反向要求用户（衰减惩罚），并反向指导用户（智能推荐），终成一个完整的教学闭环。

**7. 最终运行方式**
无需配置任何重度服务。打开 PowerShell：
```bash
g++ src/*.cpp -o project1.exe -std=c++17 -Wall
./project1.exe
```

- **体验无压靶场**：去“自测练习中心”，疯狂乱填答案，再去主界面查看，你会发现卡片的“日常掌握度”一分未掉。
