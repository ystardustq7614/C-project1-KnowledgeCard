【本轮更新日志】
- 当前版本：v1.2.3
- 对比版本：v1.2.2

本轮目标：把原本只能从菜单里运行的数据一致性检查，升级为可被自动化测试直接调用的 CLI 能力。

解决的问题：
- 自动化测试不再需要模拟登录、进入菜单、选择“数据一致性检查”。
- 检查逻辑不再只绑定 `currentUserId`，CLI 默认可检查全部用户。
- 参数错误现在有明确提示和退出码。

新增内容：
- `--check-data`：非交互检查全部数据。
- `--fix`：自动修复可修复问题。
- `--user-id <id>`：限定检查指定用户。
- `--help`：显示命令帮助。

修改内容：
- 数据一致性检查被拆成检查、修复、CLI 包装三层。
- 交互菜单继续可用，且与 CLI 共用核心逻辑。

影响范围：
- 程序启动流程。
- 数据维护模块。
- 自动化测试调用方式。

已知问题 / 剩余问题：
- CLI 当前只覆盖数据一致性检查，还没有覆盖完整业务流程测试。
- 重复 ID 仍只报告，不自动改，避免破坏已有关联。
