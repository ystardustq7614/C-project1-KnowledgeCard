【本轮更新日志】  
【版本号】  
- 当前版本：v1.2.7

【本轮目标】  
将测试隔离从“切换运行目录”升级为“程序原生支持指定数据目录”。

【解决的问题】  
- v1.2.6 的测试仍依赖工作目录隔离，脚本异常时定位和维护不够直接。  
- 主程序此前只能读写运行目录下的 `data/`。  
- 自动化测试无法显式告诉程序“本次只使用这个临时数据目录”。

【新增内容】  
- 新增 `--data-dir <path>` 命令行参数。  
- 新增 `PROJECT1_DATA_DIR` 环境变量支持。  
- CLI 检查脚本新增环境变量数据目录验证。  
- README 新增数据目录配置说明。

【修改内容】  
- `storage.cpp` 从固定文件常量改为 `dataDirectory + filename` 动态路径。  
- `main.cpp` 调整启动顺序，避免参数错误或 `--help` 时提前初始化数据文件。  
- `run_cli_checks.ps1` 和 `test_e2e_flow.ps1` 改为显式传入 `--data-dir`。

【代码级变更】  
- `src/storage.h`：暴露数据目录配置接口。  
- `src/storage.cpp`：使用 `std::filesystem::create_directories()` 创建指定数据目录；`load/save` 都走动态路径。  
- `src/main.cpp`：`CliOptions` 新增 `dataDir` 字段；解析 `--data-dir` 和 `--data-dir=...`；命令行参数优先级高于环境变量。  
- `tools/run_cli_checks.ps1`：`Invoke-ProjectCase` 自动追加 `--data-dir`；新增 `Invoke-ProjectCaseWithEnvDataDir`。  
- `tests/test_e2e_flow.ps1`：交互运行和数据检查都使用同一个显式临时数据目录。

【影响范围】  
- 普通运行不传参数时仍使用默认 `data/`，兼容原行为。  
- 自动化测试现在能更明确地隔离真实数据和测试数据。  
- `--help` 输出增加了 `--data-dir` 说明。  
- 本轮重新编译了 `project1-v1.2.exe`。
