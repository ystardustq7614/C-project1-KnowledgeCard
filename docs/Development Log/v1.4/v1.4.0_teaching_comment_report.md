# v1.4.0 教学化注释增强报告

## 版本号

- 当前版本：v1.4.0
- 对比版本：v1.3.7

## 本轮目标

按 `教学代码注释要求.md` 将项目从“已有职责说明”推进到“适合新人第一次阅读”的教学化注释版本，补齐项目级导读、文件级导读、输入输出说明、概念映射、易错点和可实验修改点。

## 解决的问题

- v1.3.7 已有源码和测试注释，但主要集中在职责与约束，新人仍需要自己推断阅读顺序和数据流。
- README 缺少直接面向学习者的“先看什么、后看什么、哪些可以暂时跳过”的导读。
- 核心源码注释没有统一使用 `[导读]`、`[输入输出]`、`[易错点]` 等教学标签，可扫描性不足。
- 算法、存储、复习、维护等关键路径虽然有说明，但对“输入如何变成输出”“改哪里能观察现象”的引导不足。
- 测试和工具脚本仍保留旧版本输出标记，和当前教学化分支版本不一致。

## 新增内容

- README 新增“教学化阅读导引”，说明项目目标、适合读者、学习点、建议阅读顺序、一次运行主流程、模块映射、首轮阅读重点、可跳过内容和实验点。
- 核心源码新增统一教学标签说明：
  - `[导读]`：说明文件或函数在整体流程中的位置。
  - `[对应流程图]`：说明概念模块和代码位置的对应关系。
  - `[输入输出]`：说明数据从哪里来、变成什么、流向哪里。
  - `[学习重点]`：标出首轮必须理解的关键逻辑。
  - `[易错点]`：标出容易误改或误解的边界。
  - `[简化说明]`：说明教学版相对真实系统的简化。
  - `[实验]`：给出可修改并观察结果的练习点。
- `docs/Development Log/v1.4/` 新增本轮教学化注释迭代报告。

## 修改内容

- `README.md`：版本从 v1.3.7 更新为 v1.4.0，并新增教学导读与 v1.4.0 版本演进摘要。
- `src/*.h`：将公共头文件的职责说明升级为标签化教学导读，强调模块输入输出、调用边界和误改风险。
- `src/*.cpp`：补充核心实现文件的教学标签，尤其是入口、存储、算法、日期、复习、练习、统计、维护和用户流程。
- `tools/*.ps1`、`tests/*.ps1`、`tests/e2e/*.ps1`：将脚本顶部说明升级为标签化导读，并把输出版本标记同步为 v1.4.0。
- `tests/test_algorithms.cpp`、`tests/test_date_utils.cpp`：将测试职责说明升级为教学标签，明确测试与业务流程的映射。
- `docs/testing.md`：一键测试成功示例更新为 `[v1.4.0] All tests passed`。

## 代码级变更

- `src/main.cpp`
  - 新增入口级 `[导读]`，说明启动、数据加载、登录、菜单分发、衰减扫描和推荐展示的整体路径。
  - 为 `parseCliOptions()`、`applyGlobalDecay()`、`displayRecommendations()`、菜单入口补充输入输出和易错点。
- `src/models.h`
  - 将模型层说明改为项目数据字典导读。
  - 对 `Card`、`WrongQuestion`、`ReviewLog`、`ReviewTask` 补充结构映射、持久化契约和关联字段误区。
- `src/storage.h` / `src/storage.cpp`
  - 强化“内存容器 <-> data/*.txt”的数据流说明。
  - 标明字段顺序、转义规则、旧格式兼容和整文件覆写的教学边界。
- `src/algo_sm2.*`、`src/algo_decay.*`、`src/algo_recommend.*`
  - 标明三类算法都是纯函数，不读写全局状态和文件。
  - 补充评分、衰减、推荐聚合与 README 规则的对应关系。
- `src/date_utils.*`、`src/utils.*`
  - 补充日期字符串、日期序号算法、多行输入协议和 UTF-8 控制台支持的学习说明。
- `src/card.*`、`src/wrong.*`
  - 补充展示序号映射、长文本输入、逻辑删除和错题转卡片联动的数据流。
- `src/review.*`
  - 补充 `Card/WrongQuestion -> ReviewTask -> algo_sm2 -> ReviewLog` 的复习闭环说明。
- `src/practice.*`、`src/stats.*`、`src/maintenance.*`
  - 标明主动练习不影响正式复习计划、统计只读、维护自动修复边界和 CLI 退出码契约。
- `tools/` 与 `tests/`
  - 脚本说明改为教学标签，突出临时目录、`--data-dir`、UTF-8 fixture、输入空行和文件断言的维护契约。

## 影响范围

- 业务行为：无变化。
- 数据格式：无变化。
- 测试行为：除输出版本前缀从 v1.3.7 变为 v1.4.0 外无行为变化。
- 文档影响：README、testing 文档和版本日志与当前教学化分支对齐。
- 维护影响：新人可以按 README 阅读顺序进入代码，关键文件顶部能直接看到该文件位置、数据流、边界和可实验点。

## 已知问题 / 剩余问题

- 本轮只增强注释与导读，不重构重复的菜单列表映射逻辑。
- `card.cpp` 与 `wrong.cpp` 中仍存在相似的展示序号映射和查询流程，后续教学化重构可抽取公共 helper。
- PowerShell E2E 输入序列仍依赖空行维持 `pauseScreen()` 节奏，虽然注释已说明，但结构仍偏脆弱。

## 下一轮建议

- 优先：抽取卡片/错题列表展示与序号映射 helper，降低新人阅读重复代码的成本。
- 次优先：把主链路 E2E 与中文 E2E 中重复的字段解析 helper 收敛到 `tests/e2e/common.ps1`。
- 后续：评估导入/导出或数据备份功能，但不要在教学化重构完成前引入复杂依赖。
