# v1.4.1 子菜单入口 TUI 统一迭代报告

## 版本号

- 当前版本：v1.4.1
- 对比版本：v1.4.0

## 本轮目标

- 在 v1.4.0 欢迎页和主菜单工作台基础上，继续把主要子菜单入口统一到 `tui` 风格。
- 优先改造标题、菜单项、输入提示和非法输入错误，不改变业务功能、输入编号和数据流。

## 解决的问题

- v1.4.0 只完成欢迎页和登录后主菜单，进入卡片、错题、复习、自测、统计和维护模块后仍回到旧式 `====` 文本菜单。
- 子菜单的错误提示仍是普通 `cout` 文本，和主菜单的统一提示风格不一致。
- 各模块菜单缺少简短说明和菜单项 hint，用户进入模块后需要重新理解每个入口的作用。

## 新增内容

- `tui` 模块新增通用子菜单渲染能力 `renderSubMenu()`。
- `tui` 模块新增 `TuiMenuItem` 结构，统一描述菜单编号、菜单名称和辅助 hint。
- 卡片、错题、今日复习、自测练习、统计分析和数据维护六个入口子菜单新增统一窗口式面板。

## 修改内容

- 修改六个业务模块的 `showXxxMenu()` 函数，使其调用 `renderSubMenu()` 输出标题、说明和分组菜单。
- 将这些入口菜单中的“输入无效”和“菜单选项不存在”改为 `printTuiNotice(TuiNoticeLevel::Error, ...)`。
- README、测试文档和测试脚本版本前缀同步到 v1.4.1。

- `src/practice.cpp`

  - `showPracticeMenu()` 改为统一面板，保留随机抽查和薄弱点专项突破入口。

## 影响范围

- 影响六个子菜单入口的展示样式和入口层非法输入提示。
- 不影响菜单编号、业务函数调用顺序、存储格式、命令行参数、数据结构或自动化输入脚本。
- 模块内部表单、查询结果页和业务成功提示仍保留原有文本风格，留给后续版本逐步统一。
