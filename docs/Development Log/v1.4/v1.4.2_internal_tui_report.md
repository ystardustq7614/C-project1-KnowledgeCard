# v1.4.2 模块内部 TUI 统一与工作区清理报告

【版本号】

- 当前版本：v1.4.2
- 对比版本：v1.4.1

【本轮目标】

- 在 v1.4.1 已统一子菜单入口的基础上，继续把模块内部表单、查询结果、业务成功 / 警告 / 错误提示统一到 `tui` 风格。
- 处理工作区中 `data/cards.txt`、`data/wrongs.txt` 的本地数据改动。
- 清理上一轮遗留的临时构建产物 `project1_v141_build_check.exe`。

【解决的问题】

- v1.4.1 进入具体业务页面后，新增 / 修改 / 删除 / 查询 / 统计 / 维护等页面仍大量使用旧式 `====` 标题和裸文本提示，本轮改为统一页面标题、小节标题和状态通知。
- 用户登录、注册、改密等入口仍是旧式表单，本轮统一接入 `renderPageHeader()` 和 `printTuiNotice()`。
- 存储写入失败仍输出裸 `[错误]`，本轮改为 `tui` 错误通知。
- `data/cards.txt` 与 `data/wrongs.txt` 的内容已恢复到与 HEAD 一致；校验哈希分别与 `HEAD:data/cards.txt`、`HEAD:data/wrongs.txt` 相同。

【新增内容】

- `renderPageHeader(title, subtitle)`：为模块内部页面提供统一窗口式标题。
- `printTuiSection(title)`：为统计结果、复习项、数据检查汇总提供轻量小节标题。
- `v1.4.2_internal_tui_report.md`：记录本轮与 v1.4.1 的增量差异、验证结果和剩余问题。

【修改内容】

- 用户、卡片、错题、复习、自测、统计、维护模块的内部页面标题由旧式分隔线改为 `tui` 页面标题。
- 业务成功、警告、错误、取消、无数据提示由裸 `cout` 文本改为统一通知。
- 统计结果和数据一致性检查结果增加小节标题，降低大段纯文本的阅读压力。
- 测试脚本输出前缀从 `[v1.4.1]` 同步到 `[v1.4.2]`。
- README 与 `docs/testing.md` 更新为 v1.4.2 状态。

  - 错题 CRUD、查询、分类查看、全部查看、错题转卡片页面接入 TUI 标题与通知。

- `project1.exe` 被正在运行的进程占用，导致本轮无法覆盖主程序二进制；源码已通过临时 exe 编译和分层回归验证。

- 优先关闭正在运行的 `project1.exe` 后，重新执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\run_all_tests.ps1`，让主程序二进制和一键回归入口都回到标准路径。
