# v1.4.4 序号与底层字段术语治理报告

【版本号】

- 当前版本：v1.4.4
- 对比版本：v1.4.3

【本轮目标】

- 继续审视所有“编号”相关文案。
- 用户可操作的连续数字统一称为“序号”。
- 底层持久化字段只在当前文档的数据模型章节展开说明，其他位置改用“底层主键”“关联字段”“持久化主键”等更清晰的表述。

【解决的问题】

- v1.4.3 已隐藏底层主键数值，但当前 README、测试说明、源码注释和维护输出中仍残留“编号 / 全局 ID / 字段名外露”等混杂表述。
- 用户视角的“序号”和文件视角的“底层主键”容易混淆，本轮明确二者边界。
- 数据一致性检查中的重复记录提示仍使用“内部编号”，本轮改为“重复记录”，避免用户把它理解为可操作序号。

【新增内容】

- 新增本报告，记录 v1.4.4 术语治理边界：
  - 交互层：只说“序号”。
  - 当前文档非数据模型章节：只说“底层主键 / 关联字段”。
  - 数据模型章节：可以展开具体字段名，并说明这些字段属于内部 ID 或内部关联字段。

【修改内容】

- README 更新到 v1.4.4，当前说明从“隐藏 ID”推进为“序号与底层字段术语治理”。
- `docs/testing.md` 中的测试说明不再直接展开关联字段名，改为“错题转卡关联字段”。
- CLI 与维护输出去掉“用户 ID / 内部编号”等容易误解的表述。
- 源码头文件和关键注释改用“展示序号 / 持久化主键 / 关联字段 / 自增键”等术语。
- 测试脚本输出前缀同步到 `[v1.4.4]`。

【代码级变更】

- `src/main.cpp`
  - `--user-id` 参数错误提示改为“需要跟一个正整数”。
  - 不存在用户时提示“不存在指定用户”，不再输出“用户 ID”文案。
- `src/maintenance.cpp`
  - 检查范围从“用户 ID N”改为“指定用户 N”。
  - 重复记录提示改为“重复记录（具体底层值已隐藏）”。
- `src/storage.h` / `src/storage.cpp`
  - “编号生成”改为“自增键生成”。
- `src/models.h`
  - 模型字段注释统一为“内部 ID / 内部关联字段”，便于开发者区分文件字段与界面序号。
- `src/card.h` / `src/wrong.h`
  - 注释中统一“展示序号 / 持久化主键 / 关联字段”。
- `src/card.cpp` / `src/wrong.cpp`
  - 移除旧的“编号”输出注释，避免后续误恢复。
- `README.md`
  - 当前版本、项目结构、版本演进、验收标准和后续建议更新到 v1.4.4。
  - 具体字段名集中保留在“核心数据模型”章节。
- `docs/testing.md`、`tools/*.ps1`、`tests/*.ps1`
  - 测试说明和输出前缀同步到 v1.4.4。

【影响范围】

- 影响用户可见文案、维护命令输出、README、测试说明和源码注释。
- 不改变任何数据文件格式。
- 不改变 CLI 参数名、菜单序号、输入顺序、复习算法或错题转卡关联逻辑。
- 不修改历史迭代日志中的旧事实描述；历史文档仍可能记录当时版本的旧术语。
