# v1.3.5 E2E 主要分支覆盖扩展报告

## 版本号

- 当前版本：v1.3.5
- 对比版本：v1.3.4

## 本轮目标

将 E2E 从 v1.3.4 的“核心业务主链路 + 中文输入回归”扩展为覆盖主要菜单分支的分层回归体系，并保留 `run_all_tests.ps1` 作为一键验收入口。

## 解决的问题

- v1.3.4 的 E2E 只能覆盖注册、登录、新增卡片、新增错题、错题转卡片和中文输入，无法自动发现卡片编辑/删除、错题编辑/重复转卡保护、复习、练习、统计、维护等分支的回归问题。
- E2E 失败时只能定位到“业务流程”或“中文输入”两类入口，菜单分支扩展后缺少统一汇总器和 case 名称定位。
- `run_all_tests.ps1` 直接串联单个 E2E 脚本，后续继续加 case 会让总入口越来越臃肿。

## 新增内容

- 新增 `tools/run_e2e_tests.ps1`：统一 E2E 汇总入口，负责构建主程序并串联所有 E2E case。
- 新增 `tests/e2e/common.ps1`：为分支 E2E 提供路径安全、临时数据目录、程序调用、数据文件读取和断言 helper。
- 新增 `tests/e2e/test_user_flow.ps1`：覆盖注册、错误登录、正确登录、修改密码、退出登录、旧密码登录失败、新密码登录成功。
- 新增 `tests/e2e/test_card_flow.ps1`：覆盖卡片新增、查看详情、修改、关键字查询、分类查看、排序查看、多条件查询、逻辑删除。
- 新增 `tests/e2e/test_wrong_flow.ps1`：覆盖错题新增、查看详情、修改、关键字查询、分类查看、多条件查询、错题转卡片、重复转卡保护、逻辑删除。
- 新增 `tests/e2e/test_review_practice_stats_maintenance_flow.ps1`：覆盖今日复习列表、复习卡片/错题、复习历史、随机练习、薄弱点练习、7 个统计菜单、回收站查看/恢复、物理清理取消、数据一致性检查。

## 修改内容

- `tools/run_all_tests.ps1`：从直接调用单个 E2E 和中文脚本，改为调用 `tools/run_e2e_tests.ps1`。
- `tools/run_cli_checks.ps1`、`tools/run_algorithm_tests.ps1`、`tests/test_e2e_flow.ps1`、`tests/test_chinese_input_flow.ps1`：日志前缀从 v1.3.4 更新为 v1.3.5。
- README、`docs/testing.md`、`v1.3后续迭代方案.md`：补充分层 E2E 入口、分支覆盖范围和 v1.3.5 实施结果。

## 代码级变更

- `tools/run_e2e_tests.ps1`
  - 新增 `Invoke-E2ECase()`，每个 case 输出独立 START/PASS 名称。
  - 复用一次构建结果，向子脚本传入已解析的 `ExePath` 和 `-SkipBuild`，避免重复编译。
  - 串联旧主链路、中文输入回归和新增分支脚本。
- `tests/e2e/common.ps1`
  - 新增 `Resolve-E2EExecutable()`、`Invoke-E2EProgram()`、`Initialize-EmptyDataDir()`、`Remove-SafeDirectory()`。
  - 新增 `Decode-StorageField()`、`Get-RequiredLine()`、`Assert-Equal()`、`Assert-True()`，让分支脚本以数据文件断言为主。
- `tests/e2e/test_user_flow.ps1`
  - 使用独立 `.test_tmp/e2e_user_flow/data`。
  - 运行完整用户身份流，并断言 `users.txt` 中密码已更新且只保留一个用户记录。
- `tests/e2e/test_card_flow.ps1`
  - 使用独立 `.test_tmp/e2e_card_flow/data`。
  - 断言编辑后的卡片标题、标签、难度和删除状态，确认另一张卡片仍为 active。
- `tests/e2e/test_wrong_flow.ps1`
  - 使用独立 `.test_tmp/e2e_wrong_flow/data`。
  - 断言错题只转换一次、重复转换被保护、转换卡片仍可见、删除后的错题 active 为 0。
- `tests/e2e/test_review_practice_stats_maintenance_flow.ps1`
  - 预置一组干净数据，避免把复习/统计/维护测试绑定到冗长录入流程。
  - 断言 `review_logs.txt` 生成 card/wrong 两类日志，复习次数更新，回收站记录被恢复。

## 影响范围

- 测试入口：`run_all_tests.ps1` 仍是总入口，但 E2E 改由 `run_e2e_tests.ps1` 汇总。
- 临时数据：每个 E2E case 使用独立 `--data-dir`，不读写真正 `data/`。
- 业务代码：本轮没有修改 C++ 业务逻辑，只扩展自动化验证脚本和文档。

## 验证结果

已实际运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\run_e2e_tests.ps1
```

结果：通过。已覆盖核心业务、中文输入、用户、卡片、错题、复习/练习/统计/维护分支。

随后已实际运行总入口：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\run_all_tests.ps1
```

结果：通过。CLI 数据一致性检查、日期与算法单元测试、E2E 汇总套件全部通过。

## 已知问题 / 剩余问题

- E2E 仍以 smoke/regression 为目标，不覆盖所有非法输入排列。
- 复习、练习、统计、维护分支目前合并在一个较大的 case 中，后续如果该脚本继续变长，可以再拆成独立脚本。
- 跨日期登录后的真实衰减 E2E 仍未单独覆盖，当前由 `date_utils` 和 `algo_decay` 单元测试保证。
