# v1.3.0 测试闭环报告

## 1. 项目最终目标回顾

`project1` 是一个 C++17 控制台学习管理系统，核心链路是：

```text
知识卡片 / 错题录入 -> 复习调度 -> 自测练习 -> 统计反馈 -> 数据维护
```

v1.3.0 的目标不是新增业务功能，而是把 v1.2.4 ~ v1.2.9 建立的测试能力汇总为测试闭环版本，达到：

- 功能可运行。
- 测试可自动验证。
- 测试数据与真实数据隔离。
- 测试文档可维护。
- 失败时有明确排查入口。

## 2. 已实现功能清单

### 业务功能

- 用户注册、登录、修改密码、退出登录。
- 知识卡片新增、修改、删除、查询、筛选、排序、组合查询、全部查看。
- 错题新增、修改、删除、查询、组合查询、错题转知识卡片、全部查看。
- 今日复习任务生成、复习结果更新、复习日志写入。
- 自测练习中心：随机抽查和薄弱点专项突破。
- 统计分析：卡片、错题、学科分布、掌握度、复习频率、错因分类。
- 数据维护：已删除数据查看、恢复、清空回收站、数据一致性检查。
- 算法模块：简化 SM-2、记忆衰减、薄弱章节推荐。
- 数据目录配置：默认 `data/`，支持 `--data-dir` 和 `PROJECT1_DATA_DIR`。

### 测试功能

- CLI 数据一致性检查脚本：`tools/run_cli_checks.ps1`。
- 算法单元测试：`tests/test_algorithms.cpp` + `tools/run_algorithm_tests.ps1`。
- 业务 E2E 回归测试：`tests/test_e2e_flow.ps1`。
- 一键总测试入口：`tools/run_all_tests.ps1`。
- 测试说明与失败排查指南：`docs/testing.md`。

## 3. 未实现 / 主动放弃的功能清单

- 没有引入 GoogleTest，保留轻量自定义断言。
- 没有引入数据库，继续使用文本文件持久化。
- 没有新增 GUI、网络服务、账号加密或云同步。
- E2E 只覆盖核心主链路，不覆盖全部菜单分支。
- 中文输入自动化由 `tools/run_utf8_automation.ps1` 单独维护，未并入 E2E 主链路。
- `algo_decay` 日期差仍是简化实现，不作为严格日历算法。

## 4. 最终技术栈与目录结构

### 技术栈

- C++17

- 文本文件持久化

## 5. 关键设计决策回顾

- 保持轻量测试体系，不引入第三方测试框架。
- 算法测试只链接 `src/algo_*.cpp`，避免依赖控制台和文件系统。
- CLI / E2E 测试通过 `--data-dir` 使用临时数据目录，不读写真实 `data/`。
- 一键总入口只串联已有脚本，不复制脚本内部断言逻辑。
- 文档采用“先跑总入口，失败后按分层排查”的维护路径。

## 7. 最终运行方式

### 运行程序

```powershell
g++ -std=c++17 -o project1.exe src/*.cpp
.\project1.exe
```

### 指定数据目录运行

```powershell
.\project1.exe --data-dir .\.test_tmp\manual_data
```

### 数据一致性检查

```powershell
.\project1.exe --check-data
.\project1.exe --check-data --fix
.\project1.exe --data-dir .\.test_tmp\manual_data --check-data
```

## 8. 测试与验证方式

v1.3.0 的验收入口：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\run_all_tests.ps1
```

该命令覆盖：

- 主程序编译。
- CLI 数据一致性检查。
- 算法单元测试。
- 业务 E2E 回归测试。
- 临时测试目录清理。

如果失败，按 `docs/testing.md` 的分层说明排查。

## 9. 已知限制

- 仅支持控制台交互。
- 密码明文存储。
- 文本字段不支持多行，且不能包含 `|`。
- 数据文件没有并发写入保护。
- E2E 只覆盖一条核心业务主链路。
- 中文自动化输入不在 E2E 主链路中。
- `algo_decay` 日期差是简化实现。

## 10. 后续迭代建议

3. 增加数据备份、导入、导出能力。
4. 将自测练习结果可选写入日志。
5. 视需要引入更正式的复习算法。
